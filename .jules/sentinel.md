## 2024-06-25 - Add Security Headers to Production Build
**Vulnerability:** The application was missing critical security headers (Content-Security-Policy, X-Frame-Options, X-Content-Type-Options) in the production build.
**Learning:** For a Vite Single Page Application (SPA), server configurations like headers in `vite.config.ts` do not translate to the production build since the output is just static files. To secure the production app without relying on the host's configuration, security headers must be added via `<meta>` tags in `index.html`. NOTE: `X-Frame-Options` and `X-Content-Type-Options` are ignored by browsers when added via `<meta>` tags. They must be added at the server/hosting level. Therefore, only `Content-Security-Policy` and `referrer` can be reliably added via `<meta>`.
**Prevention:** When adding security headers to an SPA, use `<meta>` tags for `Content-Security-Policy` and `referrer`, but recognize that `X-Frame-Options` and `X-Content-Type-Options` must be configured in the hosting environment (e.g., `vercel.json` or `_headers`).
